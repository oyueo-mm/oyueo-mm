## About · 소개

명지대학교에서 **인공지능을 전공**하고 있는 학부생입니다. 머신러닝과 딥러닝의 원리를 이해하기 위해 알고리즘을 직접 구현하고 실험합니다. 동시에 배운 기술을 실제로 사용할 수 있는 서비스로 연결하는 데 관심이 있습니다.

I'm an **Artificial Intelligence undergraduate at Myongji University**. I study machine learning and deep learning by implementing algorithms and experimenting with them. I also enjoy turning ideas into software that people can use.

**관심 분야 / Areas of interest**

- **AI의 기초와 이론 / AI foundations & theory** — 학습 알고리즘과 인공지능의 원리
- **강화학습 / Reinforcement learning** — 에이전트의 학습과 의사결정
- **생성 모델 / Generative models** — GAN, VAE, Diffusion 등의 모델
- **그래프 신경망 / Graph neural networks** — 그래프 구조 데이터와 표현 학습
- **소프트웨어 엔지니어링 / Software engineering** — 웹 서비스 개발, 배포 및 운영

> **장기적 관심 / Long-term interests:** AGI와 인공지능 이론 / AGI and theoretical AI
