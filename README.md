## About

I'm an undergraduate student majoring in **Artificial Intelligence at Myongji University**.

I enjoy understanding how learning algorithms work beneath the surface—by studying their foundations, implementing them myself, and testing them through experiments. I also build software that applies those ideas to real problems.

**Current interests**

- **Machine learning foundations** — learning algorithms, optimization, and representation learning
- **Deep learning** — generative models, graph neural networks, and interpretability
- **Reinforcement learning** — agents that learn through interaction
- **Software engineering** — turning prototypes into usable, maintainable systems

## Selected Projects

### [Entry AI From Scratch](https://github.com/oyueo-mm/Entry-AI-From-Scratch)

**Learning AI by building it with Entry.**

A collection of hands-on machine learning and deep learning experiments implemented using **Entry**, a visual programming environment. Exploring neural networks, clustering, generative models, reinforcement learning, and more through direct implementation.

[Explore the repository →](https://github.com/oyueo-mm/Entry-AI-From-Scratch)

### [MJU Find](https://github.com/oyueo-mm/mju-lost-found)

**Making it easier to reunite people with lost belongings.**

A student-built lost-and-found web service for the Myongji University community. Combines natural-language and image-based similarity search with AI-assisted matching, messaging, and practical service features.

[Explore the repository →](https://github.com/oyueo-mm/mju-lost-found) · [Visit the web app ↗](https://mju-lost-found-vercel.vercel.app/)
